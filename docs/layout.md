# 一画面レイアウト（Phase 7）

この文書は、README の「一画面レイアウト（Phase 7）」から手順の詳細を移設したものです。

プレビュー・プロパティ・タイムラインを 1 ウィンドウにまとめた YMM4 風のレイアウトです。既定は「上段: プレビュー＋プロパティ / 下段: タイムライン全幅」で、従来に近い配置にも切り替えられます。

- **サイズ変更**: ペインの境界をドラッグします。
- **入れ替え**: ペイン上部の `⋮⋮` ヘッダをドラッグして別のペインへ重ねます。ヘッダを右クリックすると「◯◯と入れ替え」と「レイアウトを初期化」を選べます。
- **プリセット**: 「表示」メニューから「YMM4 風レイアウト」「従来レイアウト」「レイアウトを初期化」を選べます。同じメニューから各ペインへフォーカスできます。
- **保存・復元**: レイアウトは `~/Library/Application Support/MacUtl/settings/workspace-layout.json` に自動保存され、次回起動時に復元されます。開発ビルドでは実行ファイル隣の `settings/workspace-layout.json` に保存されます。
- **最小サイズ**: ウィンドウは 800×600 未満に縮小できません。パネルが極端に小さくなった場合は、内容を省略して破綻を防ぎます。
- レイアウト JSON が壊れている場合は YMM4 風レイアウトで起動します。

v1 ではペインをフローティングの別ウィンドウにはできません。システム設定・プロジェクト設定・シーン設定・キーバインド・書き出し・エフェクト追加・イージングエディタの各ダイアログは、従来どおり別ウィンドウで開きます。
